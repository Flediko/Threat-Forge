What the scanner checks

Checks for common web security issues

Nine focused checks inspect application inputs, browser protections, and security headers.

SQL Injection Detection

Tests GET and POST parameters for syntax breaks, Boolean differential queries, and MySQL/Postgres error signatures.

Cross-Site Scripting (XSS)

Validates parameter sanitization against HTML entity reflection, event handler triggers, and script payload echoes.

Command Injection

Probes input fields for shell metacharacters and blind timing anomalies across Unix and Windows environments.

Security Headers Audit

Inspects mandatory defense headers including Content-Security-Policy, HSTS, X-Content-Type-Options, and Referrer-Policy.

Cookie Flag Protections

Verifies Secure, HttpOnly, and SameSite attributes on sensitive session cookies to prevent session hijacking and theft.

Clickjacking & Framing

Checks for X-Frame-Options (DENY/SAMEORIGIN) and CSP frame-ancestors to defend users against UI redressing attacks.
